# Ассемблер для учебной виртуальной машины (УВМ)

## Описание

CLI-приложение ассемблера для перевода текстового представления команд в промежуточное представление.

## Язык ассемблера

Язык ассемблера использует формат YAML. Каждая команда представлена как элемент списка с именем мнемоники в качестве ключа и параметрами в качестве значений.

### Формат команды

```yaml
- мнемоника:
    B: значение
    C: значение
    D: значение  # опционально
```

### Поддерживаемые команды

#### 1. Загрузка константы (`const`)
Загружает константу в регистр.

**Параметры:**
- `B` (биты 4-6): Адрес регистра назначения
- `C` (биты 7-37): Константа для загрузки

**Пример:**
```yaml
- const:
    B: 2
    C: 68
```

#### 2. Чтение значения из памяти (`load`)
Читает значение из памяти и записывает в регистр.

**Параметры:**
- `B` (биты 4-6): Адрес регистра назначения
- `C` (биты 7-25): Адрес в памяти для чтения

**Пример:**
```yaml
- load:
    B: 3
    C: 823
```

#### 3. Запись значения в память (`store`)
Записывает значение из регистра в память.

**Параметры:**
- `B` (биты 4-6): Адрес регистра источника
- `C` (биты 7-13): Смещение
- `D` (биты 14-16): Адрес регистра базы

**Пример:**
```yaml
- store:
    B: 4
    C: 4
    D: 3
```

#### 4. Бинарная операция: сложение (`add`)
Выполняет сложение регистра со значением из памяти.

**Параметры:**
- `B` (биты 4-6): Адрес регистра (первый операнд и результат)
- `C` (биты 7-25): Адрес в памяти (второй операнд)

**Пример:**
```yaml
- add:
    B: 3
    C: 22
```

## Использование

```bash
python main.py <исходный_файл.yaml> <выходной_файл> [--test]
```

**Аргументы:**
- `исходный_файл.yaml` - путь к YAML файлу с программой
- `выходной_файл` - путь к двоичному файлу-результату (на данном этапе не используется)
- `--test` - режим тестирования (выводит промежуточное представление на экран)

**Пример:**
```bash
python main.py test.yaml output.bin --test
```

## Внутреннее представление

Внутреннее представление команды - это словарь с полями:
- `A` - код операции (opcode)
- `B` - адрес регистра (если требуется)
- `C` - адрес памяти или константа (если требуется)
- `D` - адрес регистра базы (только для команды `store`)
